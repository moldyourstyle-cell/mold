# MOLD Reimagined

https://mold-clothing-streetwear.lovable.app/
I want to completely rebuild my existing MOLD clothing brand website from scratch.

Existing website:
https://mold-clothing-streetwear.lovable.app/

First, study the existing website carefully and understand its:

* Brand identity
* Layout structure
* Navigation
* Typography
* Colors
* Spacing
* Product presentation
* Homepage hierarchy
* Category structure
* Product cards
* Buttons
* Shopping flow
* Mobile responsiveness
* Overall streetwear aesthetic

IMPORTANT:
I do NOT want a direct copy of the existing website's code.

I want a NEW, cleaner, more premium and production-ready website that feels like the same MOLD brand.

The new website should preserve the brand identity and visual language of the current website while improving the UI, UX, performance and shopping experience.

# BRAND

Brand name: MOLD

Industry: Premium streetwear / fashion

Location: Chennai, Tamil Nadu, India

Brand positioning:
MOLD is a streetwear clothing brand focused on heavy, oversized, contemporary clothing with a strong visual identity.

Brand personality:

* Bold
* Minimal
* Raw
* Urban
* Youthful
* Premium
* Confident
* Slightly rebellious
* Fashion-forward

Brand feeling:
"Don't fit into the mold. Create your own."

The website should feel like a modern independent streetwear label rather than a generic e-commerce template.

# DESIGN DIRECTION

Create a premium editorial streetwear website.

Use:

* Strong typography
* Large visual sections
* Generous whitespace
* High-quality product photography
* Minimal color palette
* Strong black/white contrast
* Subtle animations
* Clean product grids
* Large typography
* Editorial fashion layouts

Avoid:

* Generic Shopify-looking layouts
* Excessive gradients
* Excessive rounded cards
* Cartoonish UI
* Too many colors
* Unnecessary animations
* Cluttered sections
* Cheap-looking e-commerce design

The design should look similar in quality and visual confidence to premium modern streetwear brands.

# MOBILE EXPERIENCE

Mobile is extremely important.

The website must be designed mobile-first.

Create:

* Sticky mobile navigation
* Mobile menu
* Easy cart access
* Large touch targets
* Swipeable product galleries
* Fast-loading images
* Responsive typography
* Responsive product grids

Do NOT simply shrink the desktop website.

Design a proper mobile experience.

# ANIMATIONS

Use subtle premium animations:

* Smooth page transitions
* Image hover effects
* Product image transitions
* Fade/slide animations
* Navigation transitions
* Cart drawer animation
* Button hover states

Animations must be fast and subtle.

Do not over-animate the website.

Do not change the brand name.

Brand:
MOLD

The final website should feel like:

# CONTENT / PRODUCTS

Use the existing website's products and categories as the initial content structure, but make the product data easy to replace later.

Create a clean product data structure so I can easily add:

* Product name
* Images
* Price
* Sale price
* Sizes
* Description
* Category
* Stock
* SKU
* Product tags

# ADMIN / DATA

Structure the project so that products, inventory, prices and images can be easily managed later.

Do not hardcode the entire product catalog into UI components.

Separate:

* Product data
* UI components
* Pages
* Navigation
* Configuration

# TECHNICAL REQUIREMENTS

Use a modern production-ready architecture.

Keep components reusable.

Create reusable components for:

* Header
* Footer
* ProductCard
* ProductGrid
* ProductGallery
* CategoryCard
* Button
* CartDrawer
* Newsletter
* AnnouncementBar

Use clean and maintainable code.

Make sure there are no broken links, console errors or placeholder interactions.

# FINAL GOAL

The final result should look like a completely new version of the MOLD website, not a copy.

Keep the recognizable MOLD identity from the existing website but make it:

MORE PREMIUM
MORE MODERN
MORE EDITORIAL
MORE MOBILE FRIENDLY
MORE CONVERSION FOCUSED
MORE PROFESSIONAL

Before implementing, analyze the existing website and create the new design system around the MOLD brand.

Then build the website page by page.

Do not stop at a homepage mockup.

Build the complete working website with functional navigation, product pages, cart, search, filtering and responsive behavior.
